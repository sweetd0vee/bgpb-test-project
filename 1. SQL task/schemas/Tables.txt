LOANS - таблица кредитных договоров (SCD Type 2)

id_loan - ID договора;
dt_start - дата действия версии строки (начало, включительно);
dt_end - дата действия версии строки (конец, включительно);
id_client - ID клиента;
num_loan - номер договора;
dt_open_loan - дата открытия договора;
code_curr - код валюты договора (933 = BYN, 840 = USD, 978 = EUR);
int_rate - процентная ставка по основному долгу;
risk_group - группа риска.

Открытая (актуальная) версия договора имеет dt_end = 3001-01-01.

##############################################################

CLIENTS - таблица клиентов (SCD Type 2)

id_client - ID клиента;
dt_start - дата действия версии строки (начало, включительно);
dt_end - дата действия версии строки (конец, включительно);
name_client - наименование клиента;
type_client - тип клиента (ФЛ / ЮЛ);
department - наименование подразделения клиента.

Открытая версия клиента имеет dt_end = 3001-01-01.

##############################################################

LOANS_FACT - таблица ежедневных фактов по кредитным договорам

id_loan - ID договора;
dt - дата факта (остатки по состоянию на конец этого дня);
rest_od - остаток основного долга в валюте договора;
rest_od_eq - остаток основного долга в эквиваленте на BYN;
rest_pd - остаток просроченного долга в валюте договора;
rest_pd_eq - остаток просроченного долга в эквиваленте на BYN.

Первичный ключ: (id_loan, dt). По одному договору может быть несколько дат.

##############################################################

SCD Type 2 (slowly changing dimension) — стратегия хранения истории изменений
измерения. При изменении атрибута вставляется новая версия строки, а у предыдущей
закрывается dt_end. Срез на дату D выбирается условием
dt_start <= D AND dt_end >= D.
