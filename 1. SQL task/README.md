# SQL-задание

Диалект: **PostgreSQL** (в условии упомянут Oracle; отличие указано здесь и в сдаваемом файле).
Отладка — в клиенте DBeaver (это не СУБД).

Сдаваемый файл: [`queries/SQL-task.sql`](queries/SQL-task.sql).
Он собран из [`schemas/create_tables.sql`](schemas/create_tables.sql),
[`schemas/data.sql`](schemas/data.sql) и `queries/task-N.sql`.

## Модель данных

Поля: [`schemas/Tables.txt`](schemas/Tables.txt).

- `clients` и `loans` — SCD Type 2. Версия действует на `[dt_start, dt_end]`.
- Актуальная версия: `dt_end = 3001-01-01`.
- `loans_fact` — ежедневные остатки, ключ `(id_loan, dt)`. Поля `rest_*` могут быть NULL.
- Срез на дату `D`: `dt_start <= D AND dt_end >= D`.
- Коды валют: 933 BYN, 840 USD, 978 EUR.

## Как запустить

```bash
psql -d postgres -v ON_ERROR_STOP=1 -f schemas/create_tables.sql
psql -d postgres -v ON_ERROR_STOP=1 -f schemas/data.sql
psql -d postgres -v ON_ERROR_STOP=1 -f queries/task-1.sql
```

Либо одним файлом: `queries/SQL-task.sql`. Схема начинается с `drop table if exists`.

Тестовые данные покрывают все семь запросов (в том числе `ООО%`, факты на 2022-12-31 и открытия в сентябре 2023).

## Задачи

1. На 30.09.2023: договоры в валютах 840 и 978 — `num_loan`, `risk_group`, `currency`, `rest_eq` (ОД + ПД в эквиваленте). Нулевой суммарный остаток не выводится.
2. По каждому дню сентября 2023 — сколько договоров **открыто в этот день** у клиентов-ФЛ. Берётся актуальная SCD-версия (`dt_end = 3001-01-01`). Поля: `dt_open_loan`, `cnt_loan`. Дни без открытий остаются с нулём.
3. То же для ЮЛ, разбивка по валютам. Поля: `dt_open_loan`, `cnt_BYN`, `cnt_USD`, `cnt_EUR`.
4. Наименования актуальных ЮЛ с именем `ООО%` (без учёта регистра), у которых в 2022 открыто больше одного договора.
5. Актуальные ЮЛ, открывшие больше одного договора в сентябре 2023: эти договоры, `rest_eq_deal` на 30.09.2023 и `rest_eq_client`. Нулевые остатки не отбрасываются. Сортировка по имени клиента.
6. На 31.12.2022 средневзвешенная ставка ЮЛ **только по договорам в BYN (933)**. `avg_rate` — модуль, округление до 2 знаков; плюс сумма ОД в эквиваленте. Договоры без остатка ОД не входят в расчёт. Клиент — актуальная версия. Сортировка по `avg_rate`.
7. В разрезе подразделения — число клиентов **без кредитного договора вообще** (`cnt_clients_without_loans`). Клиент — актуальная версия. Сортировка по подразделению.

## Допущения

- Где в условии сказано «последнее актуальное состояние», фильтр `dt_end = 3001-01-01`.
- Где сказано «по состоянию на дату», берётся SCD-версия, действующая в этот день, и последний факт `dt <= дата`.
- В задаче 5 в тексте есть и `rest_eq_loan`, и `rest_eq_deal`; в выборке используется `rest_eq_deal`, как в списке ожидаемых полей.
- В PostgreSQL некавыченные идентификаторы приводятся к нижнему регистру; имена `cnt_BYN` / `cnt_USD` / `cnt_EUR` поэтому закавычены.
- Составной PK SCD-таблиц не даёт повесить простой FK на `id_client` / `id_loan`.
